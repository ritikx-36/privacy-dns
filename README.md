# Privacy DNS

A DNS-based privacy and filtering project focused on blocking ads, trackers, and unwanted domains.

## Current Status

Phase 1: DNS Lookup Tool

The current version resolves a domain name and returns its IP address using Python's socket library.

## Requirements

* Python 3

## Usage

```bash
python3 dns_lookup.py
```

Enter a domain name when prompted.
